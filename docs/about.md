## The summary

* Senior technical writer with 15 years of experience in software documentation, particularly in fintech. I have been a manager for some of those years, but I still get to spend a significant amount of time on research & writing.

* I am most productive when I can be fully embedded in a cross-functional team and I can participate in the entire software lifecycle, from specifications to delivery. 

* I was a copy editor in a past life, and editing is still my forte. 

* I always migrate to the doc tools support role, and I genuinely enjoy migrations and cleanup tasks.

## The resume

As a senior technical writer, I have:

* Created and updated all types of documentation: user guides, admin guides, API guides, release notes (so many release notes).
* Maintained and improved the documentation CI/CD pipeline.
* Provided doc tools support to a department of ~20 writers (Flare, RoboHelp, FrameMaker, SVN, Git, Jira, Word, HTML, etc).
* Given presentations to internal teams and to clients.
* Automated documentation tasks.
* Coordinated the migration of a 6000-page documentation set from RoboHelp to Flare.
* Played an informal QA role.

As a manager, I have:

* Coordinated a documentation team of 3-5 within an Agile environment, with quarterly releases.
* Trained and mentored junior writers.
* Handled recruitment, from resume selection through interviewing and offers.
